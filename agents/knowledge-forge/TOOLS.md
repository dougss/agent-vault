# Tools

## Ingestao de Fontes
- summarize — resumo de URLs, PDFs, videos YouTube
- Web Fetch — leitura de paginas completas
- Read — leitura de arquivos locais (Obsidian, etc)

## Geracao de Agentes
- skill-creator — template para criacao de skills
- `openclaw agents add` — criacao de agentes via CLI

## Knowledge Base
- obsidian — acesso ao vault Obsidian-Mind (fonte de dados local)

## Visualizacao
- excalidraw — delegacao de operacoes em arquivos .excalidraw existentes (subagent pattern)
- excalidraw-obsidian — geracao de diagramas (mapas mentais, fluxogramas, arquiteturas) como .excalidraw.md no vault Obsidian

## Utilidades
- memory-hygiene — manutencao de memoria
